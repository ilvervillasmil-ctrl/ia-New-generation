1. STATE the claim precisely.  
2. SHOW the derivation using only framework constants.  
3. COMPARE with observed or accepted values.  
4. CALCULATE the error.  
5. PROVIDE automated test(s).

### For Hypotheses

1. STATE the hypothesis clearly.  
2. LABEL it as hypothesis (not result).  
3. DESCRIBE what evidence would support it.  
4. DESCRIBE what evidence would refute it.  
5. SEPARATE it from verified mathematical results.

### For Interpretations

1. PRESENT the interpretation.  
2. ACKNOWLEDGE it is interpretation, not proof.  
3. OFFER alternative interpretations where they exist.  
4. LET the reader decide.

This protects the framework from ambiguity. Mathematical results stand on their own. Hypotheses are clearly labeled. Interpretations are offered honestly.
